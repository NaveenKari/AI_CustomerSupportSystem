# Tech Stack

## Backend — Spring Boot
- **Spring Boot** — REST API and webhook endpoint
- **Spring Security** — session-based authentication
- **Spring Data JPA** — database access layer
- **Spring AI** — AI integration for ticket categorization, auto-response, and PDF-based knowledge base
- **PostgreSQL** — primary database

## Frontend — React
- **React + Vite** — UI framework and build tool
- **Tailwind CSS** — styling
- **React Router** — page navigation (ticket list, ticket detail, dashboard, knowledge base)
- **Recharts** — charts for the metrics dashboard
